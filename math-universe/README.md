# 数学星球计划（Math Universe）

**目标**：像操作 GitHub 一样操作数学——把"现象"与"解法（定理=插件）"分开，7 天从基础抵达数学最前沿。每天挑选一个式子作为"星球种子"，用 Wolfram 展开其动态轨迹，模拟其星球的诞生、发展、繁荣与毁灭，并在扩展中顿悟涉及的数学领域。

**原则**：
- 不假设自己本来就会——每个式子都是在扩展中"摸"出来的。
- 底层规则有限（对称性、守恒律、曲率、可逆性……），定理是无限的现象求解算法（插件，即装即用）。
- 一个式子必须扩展到它毁灭为止，第二天换下一个式子，逐步覆盖"地球数学"全部领域。
